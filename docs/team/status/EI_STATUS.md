# EI 업무 상태

## 1. 담당 결과

감사보고서 패키지에서 감사의견, 첨부 재무제표, 재무제표 주석,
회계정책, KAM과 감사절차를 정확하게 추출·연결하고, 원문 근거와 함께
챗봇에서 사용할 수 있는 기능을 직접 고도화합니다.

## 2. 감사보고서의 의미

팀에서 `감사보고서`라고 할 때는 감사인의 의견이 적힌 본문만 의미하지
않습니다.

```text
감사보고서 본문
+ 감사대상 재무제표
+ 현금흐름표·자본변동표
+ 재무제표 주석
+ 회계정책·중요한 추정
+ KAM·선정 이유·감사절차
```

위 전체를 감사보고서 패키지로 봅니다.

## 3. 담당 사용자 기능

### EI-1 감사보고서 핵심 근거

> “A사의 감사의견, KAM과 감사인이 수행한 주요 절차를 원문과 함께
> 알려줘.”

### EI-2 재무제표 주석·회계정책

> “A사의 수익인식 회계정책과 매출 관련 주석을 감사보고서 첨부 원문에서
> 보여줘.”

### 공동 매출 시나리오

감사대상 매출 수치, 수익인식 주석, KAM, 선정 이유와 감사절차를 YE의
사업보고서 매출구조·계약·위험 결과와 연결합니다.

## 4. 현재 작업단위

- Issue:
- 작업 Branch: `feat/<issue-number>-<summary>`
- Draft PR:
- 교차 Reviewer:
- 이번 PR에서 제외한 범위:

신규 업무에 `ei`라는 사람별 장기 Branch를 사용하지 않습니다. 한 Issue를
위한 작업 Branch를 최신 `main`에서 만들고, Merge 후 Branch와 Worktree를
정리합니다.
